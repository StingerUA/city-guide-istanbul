# City Guide — галерея и несколько филиалов одного заведения

## Возможности для партнёров

Кабинет: `https://city-guide-istanbul.nncdecdgc.workers.dev/partner` → **İşletmeler / Заведения** → добавить / редактировать.

### Фотографии
- В форме можно загрузить сразу несколько изображений JPEG, PNG или WebP.
- Максимум **60 изображений** в одной карточке. Каждый файл — не более **4 МБ**.
- Загружаются последовательно, виден счётчик загрузки. До сохранения фото доступны владельцу.
- ★ на миниатюре выбирает фотографию-обложку, × удаляет её из карточки.
- При просмотре клиент видит основную фотографию, стрелки и ленту миниатюр.
- Файлы сохраняются в закрытом Supabase Storage `city-guide-photos` и доступны
  посетителям лишь через авторизованный маршрут `/api/media/:id`; удаление из карточки
  не уничтожает сам файл из Storage.

### Карта и несколько адресов
- Раздел **Harita ve şubeler / Карта и филиалы / Map and branches** в основной вкладке редактора.
- Кликните по карте, чтобы поставить текущую точку; карту можно передвигать и масштабировать.
- Для каждого филиала сохраните **название, адрес, широту и долготу**.
- Нажмите **Şube ekle / Добавить точку** для следующего филиала. Максимум **50 точек**.
- Все точки хранятся в **одной записи заведения**, с общими фотографиями, контактами,
  описанием, услугами и настройками цен.
- Для существующих карточек без массива `locations` показывается прежняя одиночная точка;
  при первом редактировании она будет преобразована в запись филиала.
- Адрес и координаты первого филиала одновременно сохраняются в старых полях
  `address`, `lat`, `lng` для обратной совместимости.

### Как это увидит турист
- В режиме «Карта» отображаются все точки выбранных заведений, даже когда у одного
  заведения несколько филиалов.
- В карточке заведения вкладка «Местоположение» показывает все точки, адреса
  и кнопку маршрута для выбранного филиала.
- При бронировании заведения с несколькими филиалами турист выбирает филиал.
  Запись хранит `locationId` и `locationLabel`.

### База и бронирования
- `public.cg_venues.payload.locations` (JSONB): массив адресов одного заведения.
- `public.cg_bookings.location_id`: отдельная идентификация филиала (для старых заявок `main`).
- `public.cg_book_atomic` проверяет корректность выбранного филиала и свободные места
  **только в этом филиале**; общая вместимость из карточки применяется отдельно к каждой точке.
- Миграция: `supabase/migrations/20261014_0003_venue_branch_bookings.sql`.
- Проверка в SQL проведена в транзакции с откатом: два независимых филиала,
  дублированный запрос, переполненная точка, неизвестная точка.

### Ограничения
- У филиалов общие часы, цены, описание, контакты и вместимость, но слоты
  бронирования независимы. Индивидуальные цены и часы филиала — отдельная будущая возможность.
- Карта использует публичные тайлы OpenStreetMap и ссылку-атрибуцию.
  При высокой нагрузке потребуется совместимый собственный либо коммерческий тайловый провайдер.
- Большая загрузка (например, 60 фотографий по 4 МБ) расходует квоту Supabase Storage.
