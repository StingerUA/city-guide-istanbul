# City Guide — загрузка исходников в GitHub через Codespaces

Версия приложения: v0.2.1. Экспорт подготовлен 9 октября 2026 года.
Исходная версия Git: `059ab93a13edfa1d59927c04beee8fa1f341af6c`.

## Что находится в архиве

Полные исходники текущей версии приложения: кабинеты администратора, партнёра
и туриста на русском, турецком и английском языках; изображения проекта;
схема базы данных и SQL-миграции; тесты; зависимости и файл их точных версий;
план проекта и описание выполненных проверок.

158 файлов проекта и эта инструкция. Скрытые файлы настроек также включены.
Установленные зависимости, временные результаты сборки и история Git не нужны
для импорта и в комплект не входят. Рабочая база данных и фотографии,
загруженные пользователями в действующее приложение, хранятся отдельно:
это архив исходников, а не резервная копия работающего сервиса.

## 1. Создай новый репозиторий

На GitHub создай репозиторий `city-guide-istanbul` в своём аккаунте:

- Visibility: **Private**.
- Включи **Add a README file**, чтобы появилась начальная ветка.
- Остальные настройки можно оставить без изменений.

Инструкция рассчитана на новый репозиторий. Начальный README будет заменён
README проекта.

## 2. Открой Codespaces

В репозитории нажми **Code → Codespaces** и создай Codespace для его основной
ветки. Дождись открытия редактора.

## 3. Загрузи ZIP в редактор

Перетащи `City_Guide_GitHub.zip` в левую панель файлов (Explorer), в корень
репозитория, рядом с README.md. В веб-редакторе также можно воспользоваться
пунктом **Upload…** в контекстном меню панели файлов.

Сохрани точное имя `City_Guide_GitHub.zip`: оно используется в командах ниже.
ZIP должен быть загружен в файловую систему Codespace, а не добавлен как
единственный файл в репозиторий на странице GitHub.

## 4. Распакуй и отправь исходники

Открой **Terminal → New Terminal** и вставь весь блок целиком:

```bash
(
set -e
cd "$(git rev-parse --show-toplevel)"
city_guide_import_dir="$(mktemp -d)"
unzip -q City_Guide_GitHub.zip -d "$city_guide_import_dir"
cp -a "$city_guide_import_dir/city-guide-istanbul/." .
git add -- . ':!City_Guide_GitHub.zip'
git commit -m "Import City Guide v0.2.1"
git push
)
```

Команды копируют все файлы, включая скрытые настройки, прямо в корень
репозитория. Настройки подключения репозитория к GitHub сохраняются.
Сам ZIP в коммит не попадёт. Устанавливать зависимости или запускать
приложение для этого переноса не требуется.

Если любая команда завершится ошибкой, блок остановится. Сохрани текст ошибки,
чтобы можно было продолжить с того же места; повторная настройка проекта
обычно не требуется.

## 5. Проверь результат

Обнови страницу репозитория на GitHub. В корне должны появиться папки `app`,
`components`, `public`, `db`, `drizzle`, `tests` и файл `package.json`.
Проект не должен оказаться внутри дополнительной папки `city-guide-istanbul`.

После успешной отправки останови Codespace, если пока не собираешься работать
с кодом. Ссылка на репозиторий позволит продолжить разработку с этой версии.

## Что будет с действующим приложением

Перенос исходников в GitHub сам по себе не меняет размещение приложения или
выданный партнёру доступ. Приложение продолжает работать по существующей ссылке:

https://city-guide-istanbul.nick-nesterenko.chatgpt.site

Это приложение использует серверную часть, базу D1, хранилище R2 и авторизацию
текущего размещения. GitHub Pages не запускает эту серверную часть. Если позже
нужно будет перенести само работающее приложение, потребуется отдельно
настроить размещение, авторизацию и перенос рабочих данных. Codespaces на этом
шаге используется только для загрузки исходников в репозиторий.

Подробности реализации и ограничения текущей версии описаны в `README.md`.
Полный план развития находится в `docs/City_Guide_Plan_RU.md`, результаты
проверок — в `docs/VALIDATION.md`.
